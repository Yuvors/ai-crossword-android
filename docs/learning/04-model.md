# שיעור 4: מחלקות ה-model

> הקוד בשיעור הזה נכתב בעזרת AI (Claude). זה רשום ב-`docs/ai-usage.md`.

השיעור נבנה בשלבים, יחד עם הקוד:
- **חלק א' — enums** (נכתב) — `Direction`, `Arrow`, `PuzzleSize`, `PuzzleSource`, `Difficulty`.
- חלק ב' — הורשת `Cell` (בהמשך).

- חלק ד' — `Grid` ו-`Puzzle` (בהמשך).

## מערכת הקואורדינטות
לפני הכול: איך ממספרים משבצות בגריד.
```
          עמודה:  4   3   2   1   0
                ┌───┬───┬───┬───┬───┐
       שורה 0   │   │ ם │ ו │ ל │ ש │
                ├───┼───┼───┼───┼───┤
       שורה 1   │   │   │   │   │   │
```
- שורה 0 למעלה. **עמודה 0 היא הימנית ביותר**, כי בעברית קוראים מימין לשמאל.
- לכן באלגוריתם האות הבאה במילה מאוזנת היא תמיד `col + 1`, ובמילה מאונכת `row + 1`. אין מינוסים.
- רק `ArrowGridView`, שמצייר על המסך, צריך להפוך: הפיקסלים במסך נספרים משמאל. הנוסחה תהיה `x = (size - 1 - col) * cellSize`.

## חלק א': enums

### מה זה enum
`enum` הוא טיפוס עם **רשימה סגורה של ערכים**. משתנה מסוג `PuzzleSize` יכול להיות רק `SMALL` או `LARGE`, ושום דבר אחר:
```java
public enum Difficulty {
    EASY,
    MEDIUM,
    HARD
}
```
**למה לא `int`?** עם `int difficulty` אפשר להעביר בטעות 7 או -1, והקומפיילר לא יתלונן. עם `Difficulty` הקומפיילר מקבל רק את שלושת הערכים. גם הקוד קריא יותר: `Difficulty.HARD` במקום `3`.

### enum עם שדות ובנאי
enum ב-Java הוא בעצם מחלקה. לכל ערך אפשר לתת נתונים משלו:
```java
public enum PuzzleSize {
    SMALL(10),
    LARGE(15);

    private final int size;

    PuzzleSize(int size) {
        this.size = size;
    }

    public int getSize() {
        return size;
    }
}
```
- `SMALL(10)` קורא לבנאי עם 10. כל ערך הוא **עצם אחד** שנוצר פעם אחת, כשהמחלקה נטענת.
- הבנאי של enum תמיד פרטי (גם בלי המילה `private`). אי אפשר לכתוב `new PuzzleSize(12)`.
- השדה `final`: הגודל של `SMALL` לא ישתנה אף פעם.
- שימוש: `PuzzleSize.SMALL.getSize()` מחזיר 10.

כך המספר 10 כתוב במקום אחד בלבד. אם נרצה גריד של 11, נשנה שורה אחת.

### `Direction`: צעד לכל אות
```java
HORIZONTAL(0, 1),   // שורה +0, עמודה +1 — שמאלה
VERTICAL(1, 0);     // שורה +1, עמודה +0 — למטה
```
במקום לכתוב `if (direction == HORIZONTAL) col++; else row++;` בכל מקום, הקוד יכתוב:
```java
row += direction.getRowStep();
col += direction.getColStep();
```
זה עובד לשני הכיוונים בלי `if`. הנתון יושב בתוך הערך עצמו.

### `Arrow`: ארבעה חיצים
לכל חץ שלושה נתונים: איפה מתחילה התשובה ביחס למשבצת ההגדרה (שורה, עמודה), ובאיזה כיוון היא רצה:

| ערך | היסט התחלה | כיוון | שבור? |
|---|---|---|---|
| `LEFT` | `(0, +1)` | `HORIZONTAL` | לא |
| `DOWN` | `(+1, 0)` | `VERTICAL` | לא |
| `DOWN_THEN_LEFT` | `(+1, 0)` | `HORIZONTAL` | כן |
| `LEFT_THEN_DOWN` | `(0, +1)` | `VERTICAL` | כן |

```java
LEFT(0, 1, Direction.HORIZONTAL),
```
שים לב: שדה של enum יכול להיות **enum אחר** (`Direction`).

הפעולות:
```java
public int getStartRow(int clueRow) {
    return clueRow + startRowOffset;
}
```
הגדרה במשבצת `(2, 3)` עם `Arrow.DOWN` → התשובה מתחילה ב-`(3, 3)`.

```java
public boolean isBent() {
    return startRowOffset != direction.getRowStep()
            || startColOffset != direction.getColStep();
}
```
**מתי חץ שבור?** כשהצעד מההגדרה לאות הראשונה **שונה** מהכיוון של התשובה. ב-`LEFT` הצעד הוא שמאלה `(0, 1)` והתשובה רצה שמאלה `(0, 1)`: אותו דבר, לא שבור. ב-`DOWN_THEN_LEFT` הצעד הוא למטה `(1, 0)` אבל התשובה רצה שמאלה `(0, 1)`: שונה, שבור. אין צורך לשמור את זה כשדה נפרד; מחשבים מהנתונים שכבר יש.

### `PuzzleSource`
`POOL` (המאגר), `LEARNING` (תשחץ לימודי), `DAILY` (התשחץ היומי). enum פשוט, בלי שדות.

### בדיקות
`ArrowTest` בודק את הצעדים של `Direction`, את משבצת ההתחלה והכיוון של כל חץ, את `isBent`, ואת הגדלים של `PuzzleSize`.

## שאלות שבוחן עשוי לשאול
1. **מה היתרון של enum על פני `int` או `String`?** הקומפיילר מקבל רק ערכים מהרשימה, והקוד קריא יותר.
2. **מה קורה כשכותבים `SMALL(10)`?** נקרא הבנאי של ה-enum עם 10, ונוצר עצם אחד בשם `SMALL`.
3. **למה הבנאי של enum לא ציבורי?** כדי שאי אפשר יהיה ליצור ערכים חדשים מחוץ לרשימה.
4. **למה עמודה 0 היא הימנית?** כי בעברית קוראים מימין לשמאל, וכך האות הבאה במילה מאוזנת היא תמיד `col + 1`.
5. **איך יודעים אם חץ שבור?** משווים את ההיסט של משבצת ההתחלה לצעד של הכיוון. אם הם שונים, החץ שבור.
6. **שינוי שבוחן עשוי לבקש:** "הוסף גודל בינוני של 12×12." → שורה אחת ב-`PuzzleSize`: ‏`MEDIUM(12),`.
